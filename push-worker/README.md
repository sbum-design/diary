# Diary Book 휴식 알림 서버

운동 휴식 타이머가 끝나면 화면이 꺼져 있어도 아이폰으로 알림을 보내는 작은 서버입니다.
Cloudflare Workers 무료 플랜으로 동작합니다.

[![Deploy to Cloudflare](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/sbum-design/diary/tree/main/push-worker)

배포가 끝나면 나오는 주소(`https://diary-push.○○○.workers.dev`)를 Diary Book → 운동 → 「휴식 알림」 칸에 붙여넣으세요.
